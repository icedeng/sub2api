# v0.2.24 本地合并记录

2026-11-20，`main-wayvia` 在 `932322cdd`（含上游低余额邮件告警）之上合并正式标签 `v0.2.24`（`5c2982a81`），合并提交 `b644ddc68`。两个分支的共同祖先是 `v0.2.23`。按仓库约定，构建版本为 `0.2.24-wayvia`。

## 定制与上游改动

上游修改 190 个文件，Wayvia 相对共同祖先修改 216 个文件，交集为 20 个。合并时逐文件比较了双方差异。196 个仅 Wayvia 修改的文件与自有基线一致。17 个自动合并的交叉文件中，Wayvia 补丁的新增行、删除行及顺序与合并前一致。其余三个文件手工合并。

- `VERSION` 按上游发布标签设置。该标签内的原始文件仍写作 `0.2.23`。
- Codex 上下文解析同时接受 Wayvia 的环境浏览器标签与上游新增的 IDE 上下文、计划分片及不可信内容。两侧都经过现有内容校验。
- OAuth 刷新降级路径中，Wayvia 固定出口成功提交的凭据直接进入缓存同步。普通 OpenAI OAuth 采用上游的新逻辑，按刷新时读取的原凭据进行条件写入，避免并发覆盖或超时后重复轮换。

工作区原有四个未提交文件涉及 API Key 测试模型列表与固定出口账号退役。三个文件逐字节核对，一个交叉文件按新增与删除行核对。这些改动继续保留在工作区，合并提交不包含它们。

本版对重复请求字段的校验更严格，依赖重复字段的调用方需要调整。上游还修复了文献检索 403 误停普通 OAuth 账号的问题。对固定 IPv6 账号，Wayvia 仍按既有策略拒绝尚未适配的检索路径。从前一版到该合并提交没有 SQL 迁移变更。
