实施日期：2026-11-16；已于 2026-11-17 08:17:32（Asia/Shanghai）部署到 Hostodo 服务器并执行迁移 251，发布编号 `20261117T001134Z`。部署检查未主动调用真实模型或刷新 Token；页面与真实业务流程仍由管理员最终验收。发布证据见 [发布记录](../../wayvia.dev/releases/20261117T001134Z/DEPLOYMENT.md)。

## 使用入口

- **系统设置 → 账号健康**：全局内容、平台／账号类型默认模型与内容、总并发、超时、自动策略、保留周期、继承统计及已有账号预览应用。
- **账号列表 → 健康摘要**：账号继承／排除／覆盖、生效来源及检测历史。
- **账号列表 → 勾选账号／全部筛选结果 → 批量测试**：先冻结账号集合，再确认执行；返回一个批次，不创建周期计划。
- **测试连接**：继承内容、默认 `hi`、本次自定义及仅后端渲染的预览；执行时显示实际内容与配置版本。
- **定时测试**：保留旧计划和历史接口，支持独立内容覆盖。计划与内容旁表在同一事务中保存。

首版统一执行普通 OpenAI OAuth 与 OpenAI API Key 文本检测。Agent Identity、图片、语音、视频、搜索和压缩等专项流程保持独立；不支持的内容覆盖会明确报错。

## 默认值与继承

全局配置使用 `settings.wayvia_account_health_v1`，账号标记使用 `extra.wayvia_health_check`。设置保存采用版本校验，冲突要求重新加载。

| 配置 | 默认值 |
| --- | --- |
| 内容 | 空，实际使用 `hi` |
| 检测总并发 | 1，范围 1–10 |
| 单次超时 | 45 秒，范围 10–120 秒 |
| 错误后模型复检／周期探测／成功自动恢复 | 均关闭 |
| 自动策略账号类型 | 普通 OpenAI OAuth；API Key 需显式纳入 |
| 周期间隔／错误冷却 | 60／10 分钟 |
| 跳过近期同维度成功 | 开启 |
| 历史保留 | 每账号 100 条，最长 30 天 |

新建／导入账号仅补充 `inherit` 标记。旧账号缺少标记时保持“尚未纳入”，必须预览确认后应用；已有 `exclude`、`override`、独立计划与人工暂停保持。标记不等于启用账号，也不会绕过既有出口和调度开关。

内容优先级为：本次覆盖 → 独立计划 → 账号覆盖 → 平台／类型覆盖 → 全局 → `hi`。缺失／`null` 为继承，显式空字符串为 `hi`。有效多行随机抽取一行，重复行保留权重；每次逻辑检测只展开一次。变量支持 `time/date/datetime/timestamp/rand/rand:min-max`，使用站点时区。模板上限 16 KiB、100 个有效候选、单行及展开内容 2 KiB；未知变量保留并提示，不执行表达式。

## 执行与状态边界

- 单测、批量、独立计划、新探针共用数据库总并发限制和同凭据活动任务约束；影子与凭据 owner 不重复并发检测。
- 批量任务原子入队；历史使用时间与任务 ID 组合游标，同一批次相同时间戳不会漏页。
- 独立计划按计划 ID 与原到期时间去重；进程中断后，过期运行租约与未认领的交互任务取消，不立即重放。
- 自动任务发送前复核策略、凭据、模型配置、代理与出口版本；账号类型变化后不切换到其他专项检测器继续执行。
- 普通 OAuth 401 保留可续期语义；开启错误复检时，复用既有带锁刷新，并对失败快照加写入保护。明确撤销、无 RT、模型配置错误不会循环探测。不会整列回写请求开始时的旧 RT。
- 网络、5xx、429 仅在显式开启后复检；有限退避为 1、5、15、60 分钟，尊重更晚的重置及冷却时间。WS 故障不会伪装成 HTTP 探针成功。
- 额度主查询与重置卡详情查询分别记录。HTML／Cloudflare 403 保留免罚语义；普通结构化 403 使用短期冷却，不向无凭据版本的账号 strike 缓存累积新检测结果。既有业务网关的分类与计数流程保持。
- 成功必须有完整响应终止证据。HTTP 200、首 token、截断或 `response.incomplete` 均不足以证明成功；HTTP 200 内明确的认证错误仍进入认证分类。
- 自动恢复只清理 `wayvia_health:<任务 ID>` 对应、且凭据／模型／协议一致的临时标记，不重新开启人工暂停，不清理额度、其他模型限流或辅助查询失败。
- 新健康结果写入使用凭据快照校验，避免迟到结果污染重新授权后的账号。关闭或修改策略后，在途自动结果只记录；明确认证撤销仍按安全规则处理。
- 不消费重置卡、不复制用户业务、不改变已有 IPv6、插件与 TLS 传输路径；新增检测不会触发无关的 Team 扩散停用或重置卡消费通知。

## 管理接口

均位于现有管理员鉴权与审计链，新增敏感接口不开放给受限管理密钥；变更接口接入已有 step-up 校验。

| 方法与路径（前缀 `/api/v1/admin`） | 用途 |
| --- | --- |
| `GET/PUT /account-health/settings` | 全局配置、版本和覆盖统计 |
| `POST /account-health/preview` | 本地渲染，不出网 |
| `GET/PUT /accounts/:id/health-policy` | 生效配置与账号策略 |
| `POST /account-health/apply` | `confirm=false` 预览；确认提交冻结 ID 集合 |
| `POST /account-health/batch-tests/preview` | 冻结目标及展示并发／超时 |
| `POST /account-health/batch-tests` | 建立一次性批次 |
| `GET /account-health/test-runs` | 按账号／批次／来源查询；支持 `before`、`before_id` |
| `GET /account-health/summaries` | 当前页账号摘要，单次最多 200 个账号 |

单次测试与计划 CRUD 保持原接口，增加可选 `test_content`。旧客户端不传时正常继承；空全局配置保持原 `hi`。实际内容仅在管理界面按纯文本显示，审计中屏蔽模板和渲染内容，不记录完整上游错误正文。
